# Thiệp cưới Đức Hoà & Thuý Hằng

Trang thiệp cưới online (mẫu Song Hỷ), chạy tại https://thiepcuoi.aiglobalvn.com

| Tệp | Dùng để |
|---|---|
| `index.html` | Trang thiệp |
| `beautiful-in-white.mp3` | Nhạc nền |
| `og-image.jpg` | Ảnh xem trước khi gửi link qua Zalo / Facebook |

Link mời riêng cho từng khách được tạo trong Google Sheet danh sách khách mời, dạng
`https://thiepcuoi.aiglobalvn.com/#g<mã họ tên>-zzz<mã vai vế>`.
Có thể tự tạo link tại `https://thiepcuoi.aiglobalvn.com/#tao-link`.
